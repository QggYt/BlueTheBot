# blue

**blue** is a powerful, feature-rich Discord bot designed to enhance your server experience with comprehensive moderation, AI chat, automation, community, economy, utility, and entertainment features. Built with modern Discord.js v14 and PostgreSQL for performance and persistent data.

## Features Overview

Blue offers a complete suite of tools for Discord server management and community engagement:

<tr>
<td width="50%" valign="top">

### Moderation & AutoMod
- **AutoMod** - Anti-spam and message protection
- **Invite Protection** - Detect Discord invite links
- **Mention Protection** - Detect excessive mentions
- **Caps Protection** - Detect excessive uppercase spam
- **Repeated Message Protection** - Detect message flooding
- **Automatic Timeouts** - Apply temporary moderation actions
- **Mass Actions** - Bulk ban/kick capabilities
- **User Notes** - Keep detailed moderation records
- **Case Management** - View and track moderation actions

### AI Chat
- **Gemini AI** - Natural conversational AI
- **Mention Chat** - Mention Blue to talk with it
- **Conversation Memory** - Short per-user/channel context
- **Discord Mentions** - AI can use explicitly mentioned users and roles
- **Free-tier Support** - Gemini API configuration

### Economy System
- **Shop & Inventory** - Buy and manage items
- **Gambling** - Risk it for rewards
- **Pay System** - Transfer money between users

### Fun & Entertainment
- **Random Facts** - Learn something new
- **Random Topics** - Generate conversation starters
- **Wanted Poster** - Create fun wanted images
- **Text Reversal** - Reverse any text

### Advanced Ticket System
- **Claim & Priority** - Staff ticket management
- **Ticket Limits** - Prevent spam
- **Transcript System** - Save ticket history

### Server Stats
- **Member Counter** - Live member count channels
- **Voice Counters** - Track voice stats
- **Dynamic Updates** - Real-time channel updates

### Reaction Roles
- **Role Assignment** - Self-assignable roles
- **Emoji Selection** - Reaction-based system
- **Multi-role Support** - Multiple role options
